# 🔬 牛顿环实验测量工具

基于 **OpenCV.js** 和 **Vue 3** 的浏览器端自动图像识别与曲率半径计算系统，专为大学物理实验设计。全部计算在浏览器内完成，**无后端、无数据库、无需安装依赖**。

工具分为两个板块（顶部标签切换）：

- 📏 **像素标定与位移测算**：由测微鼓轮位移标定出真实的「mm/像素」，并测算位移。
- 🔬 **环纹识别与人机校验**：自动识别牛顿环暗环，人工校验后计算各环直径、逐差法曲率半径与不确定度。

> 详细分步操作见 [`操作流程与建议.md`](操作流程与建议.md)；开发交接与已知注意事项见 [`交接文档.md`](交接文档.md)。

## ✨ 核心功能

### 📏 像素标定与位移测算

- **双图对比标定**：上传转动测微鼓轮前后拍摄的图A / 图B（同机位、同尺寸），测算真实像素标定值。
- **✂️ 圆形截取**：在图A上框选圆形区域，两图按完全相同位置截取，只对标定关心的环区做对齐（可跳过，直接对齐全图）。
- **🔍 叠加对齐（两条路径任选）**：
  - **手动对齐**：拖滑块 / 方向键移动图B，参考重合度残差，配合 **闪烁对比**（错位环纹跳动、对齐后消失）辅助判读；**检查对齐** 给出基于整图相关的权威残差、PSR 置信度与方向建议。
  - **自动全局对齐**：一键从任意偏移直接求解完整平移量（亚像素），基于整图相关 + PSR 置信闸门。
- **⭕ 辅助对齐圆环 / 观察模式**：可拖拽的霓虹同心参考环、彩色 / 灰度叠加，均为纯视觉辅助，不改变像素、不参与配准。
- **取点与标定值**：对齐锁定后在叠加画面点击同一特征点（支持多组），输入鼓轮刻度自动算物理距离，得 **标定值 = 物理距离 ÷ 像素距离**（固定 4 位有效数字），一键应用到环纹识别板块。
- **自动缓存**：标定图片、特征点、刻度、截取状态存入 sessionStorage，刷新不丢。

### 🔬 环纹识别与人机校验

- **自动检测**：上传后自动定位圆心、识别暗环（也可一键导入标定板块的图A / 图B）。
- **🎯 第一步 · 圆心确认**：自动检测圆心后人工核对，可拖拽 / 方向键微调 / 输入坐标，圆心允许移到图片范围外；`+/−` 调节十字光标臂长。
- **✋ 第二步 · 环人工核对**：默认全部勾选，可取消勾选剔除误检环、直接修改环编号、在图上点击补入漏检环；未勾选环不参与计算。
- **⛶ 全屏放大补环**：一键自动取景并等比放大到全屏，滚轮缩放 / 拖拽平移 / 点击补环，底部实时显示原图坐标与半径。
- **参数调试面板**：8 项预处理参数（亮度、对比度、模糊、灰度、锐化、边缘增强、CLAHE Clip、CLAHE Tile），实时 CSS 预览，「重新处理」走 OpenCV 真实管线。
- **📊 测量与不确定度**：
  - 表1：各暗环直径（像素 / 毫米）；
  - 表2：**逐差法**曲率半径，步长 (m−n) 默认 5、可人工调节、动态分组无组数上限；
  - **平均曲率半径 R̄ ± 扩展不确定度 U**（p = 0.683、k = 1，A 类统计 + B 类仪器误差传播，五步评定可展开）。
- **交互式可视化**：Canvas 叠加检测圆环、编号、圆心十字；鼠标悬停圆环 ↔ 表格行双向联动高亮。

### 💾 数据管理

- **SessionStorage 持久化**：图片与检测结果自动缓存，刷新不丢失（像素标定值 `pixelScale` 有意不持久化）。
- **CSV 导出**：直径表 + 曲率半径表 + 不确定度等元信息，含 BOM，Excel 直接打开不乱码。
- **PNG 导出**：底图 + 标注层合并的识别结果截图。
- **多图片管理**：批量上传、切换、删除；拖拽上传在环纹识别板块生效。

### 操作流程（概览）

## 📐 物理原理

### 牛顿环干涉

牛顿环是由平凸透镜与平面玻璃之间的空气薄膜产生的等厚干涉现象。当单色光垂直照射时，形成明暗相间的同心圆环。

### 曲率半径公式（逐差法）

利用暗环直径计算透镜曲率半径：

**R = (Dm² - Dn²) / [4(m - n)λ]**

其中：
- **R**：透镜曲率半径（米）
- **Dm, Dn**：第 m 环和第 n 环的直径（毫米）
- **m, n**：环的级数
- **λ**：入射光波长（钠光波长 589.30 nm）

采用**逐差法**：按步长 (m−n) 动态分组（默认步长 5，如 D_m 与 D_{m−5}），各组独立算 R 后取平均，以充分利用多环数据、抑制随机误差。

### 不确定度评定

平均曲率半径给扩展不确定度（p = 0.683、包含因子 k = 1）：

- **A 类** `u_A(R̄)`：多组 R_i 的统计标准差；
- **B 类** `u_B`：由读数显微镜示值误差限 Δ 传播——单次读数 `u_B(x) = Δ/k = Δ`，直径为两次读数之差 `u_B(D) = √2·Δ`，再逐组传播到 R；
- **合成** `u_C = √(u_A² + u_B²)`，**扩展** `U = k·u_C`（k = 1），最终 `R = (R̄ ± U) m`。

### 核心算法流程

1. **图像预处理**：灰度化 → CLAHE 对比度增强 (clip 1.5, tile 16) → 中值滤波去噪 (3×3)。
2. **圆心检测**：霍夫圆检测最大圆（外边界）→ 失败时退回亮度加权质心 → 在 ±15px 局部网格用「圆周亮度标准差最小」精修。
3. **暗环检测**：多角度径向剖面采样（双线性插值）→ Savitzky-Golay 平滑 → 局部最小值查找 → 非极大值抑制 → 半径聚类 → **r²∝m 线性拟合精修** → 按半径升序编号 1..N。
4. **人机校验**：圆心确认（第一步）→ 环勾选 / 改编号 / 补环（第二步），人工兜底自动识别。
5. **数据计算**：直径 → 逐差法曲率半径 → 平均值 → 不确定度评定。

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 亮度 | 0.5 - 2.0 | 1.0 | 图像亮度调节 |

> 调整时为实时 CSS 预览，点「重新处理」后按 OpenCV 管线重新检测；其中 CLAHE 参数会真正参与检测，务必以检测结果为准。

### 物理常量与默认值

- **钠光波长 λ**：589.30 × 10⁻⁹ m（定义于 `constants.js`，换光源需改代码）
- **读数显微镜示值误差限 Δ**：0.002 mm（用于直径 B 类不确定度）
- **逐差法步长 (m−n)**：默认 5，可人工修改（会话内保留，刷新恢复默认）
- **像素标定值**：**无默认值**，需从标定板块应用或手动输入；未设定时相关物理量显示 `—`

## ❓ 故障排查

**Q: 无法检测到暗环？**
- 检查图片质量，确保牛顿环清晰、中心光斑未被遮挡；
- 调高对比度 / CLAHE 参数后「重新处理」。

**Q: 圆心位置偏移？**
- 在「第一步：圆心确认」中拖拽 / 方向键微调 / 输入坐标；圆心可移到图片外；
- 或点「重新检测圆心」，必要时调整亮度 / 对比度后重试。

**Q: 环数不对（多检 / 漏检）？**
- 在「第二步：环人工核对」取消勾选剔除误检环、点击图上位置补入漏检环；
- 调整模糊 / 锐化参数；确保图片分辨率足够（建议 > 800px）。

**Q: 直径 mm 列 / 表2 显示 `—`？**
- 未设定像素标定值。请先到标定板块标定并「应用此标定值」，或在识别板块手动输入。

**Q: 两图无法叠加对齐？**
- 图A / 图B 尺寸不一致。请使用同一机位拍摄、尺寸相同的两张图片。

**Q: 刷新后数据丢失？**
- 多为 sessionStorage 超限（约 5MB，图片以 base64 全文存储）静默失败；减少图片数量或尺寸（建议宽度 < 2000px）。

**Q: 加载缓慢或卡顿？**
- OpenCV.js 首次加载约需 5-10 秒（9.7MB）；大图处理 2-5 秒属正常。
